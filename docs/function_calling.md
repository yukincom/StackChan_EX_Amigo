# Function Calling

## Amigo版で使える built-in function

全て音声入力で対応します。

| No. | 関数名 | 役割 | 補足・入力例 |
| --- | --- | --- | --- | --- | --- |
| 1 | `timer` | アラームまたは指定秒後の電源OFF | 「３０秒後にシャットダウンして」 |
| 2 | `timer_change` | 実行中タイマーの変更またはキャンセル | 「タイマーキャンセル」 |
| 3 | `get_date` | 今日または指定日の年月日を返す | 「今日は何日？」<br> 年を省略すると今年扱い |
| 4 | `get_time` | 現在時刻を返す | 音声 | 「今何時？」 |
| 5 | `get_week` | 今日または指定日の曜日を返す | 「今日は何曜日？」<br>「5月24日は何曜日？」<br> 年を省略すると今年扱い |
| 6 | `register_wakeword` | ウェイクワード登録を開始する | 「ウェイクワード 登録」<br> 合図の後に録音し、成功すると `no.Xを登録したよ！` と表示<br> 空きがない場合は `空きがないよ` |
| 7 | `wakeword_enable` | ウェイクワードを有効化する | 「ウェイクワード 有効」<br> 「ウェイクワード オン」 |
| 8 | `wakeword_disable` | ウェイクワードを無効化する | 「ウェイクワード 無効」<br> 「ウェイクワード オフ」 |
| 9 | `delete_wakeword` | 指定番号のウェイクワードを削除する | 「ウェイクワード 1 削除」 <br>  成功時 `no.Xを削除したよ！` <br> 未登録なら `消去済みだよ` <br> 範囲外なら `その番号はないよ` |

### No.6〜9 のウェイクワード系 function について

- 対応機種　`CoreS3`
- SD カード上の /app/AiStackChanEx/SC_ExConfig.yamlで、`wakeword.type` を `0` (`SimpleVox`) にしてください。

## Function Calling ではないが近い機能

以下は会話中に動きますが、**Function Calling ではありません**。

### 天気

天気は `server` 側の通常会話ショートカットです。

- 「今何時？」→ function
- 「天気を教えて」→ `server` 側 shortcut

天気の取得時間は `ConfigUI` で調整できます。

### Vision / カメラ起動

`見て` / `撮影して`、および AI 判断によるカメラ起動
