# 音声で呼び出す機能（Function Calling）

Amigo serverの `タッチ`入力では、発話テキストのルール判定で本体の関数を選び、firmware側で実行します。LLMが任意の関数を自由に選ぶ仕組みではありません。`いつでも`の会話event経路には、この関数呼出しは接続されていません。

## タッチ入力で対応する呼出し

以下は現在のserverの判定条件に合う入力例です。音声認識結果や言い回しによっては呼び出されません。

| 関数名 | 役割 | 入力例 |
| --- | --- | --- |
| `timer` | 指定時間後にアラーム、または電源OFF | 「30秒のタイマーをセットして」「30秒のタイマーをセットしてシャットダウン」 |
| `timer_change` | 実行中タイマーの時間変更・キャンセル | 「タイマーを60秒に変更」「タイマーキャンセル」 |
| `get_date` | 今日または指定日の日付 | 「今日は何日？」「明日は何日？」 |
| `get_time` | 現在時刻 | 「今何時？」 |
| `get_week` | 今日または指定日の曜日 | 「今日は何曜日？」「5月24日は何曜日？」 |
| `register_wakeword` | ウェイクワード登録の開始 | 「ウェイクワード登録」 |
| `wakeword_enable` | ウェイクワードの有効化 | 「ウェイクワード有効」「ウェイクワードオン」 |
| `delete_wakeword` | 指定番号のウェイクワードを削除 | 「ウェイクワード1削除」 |

日付の年を省略すると今年として扱います。ウェイクワード系は、CoreS3で `ENABLE_WAKEWORD` を有効にしたfirmwareと、SDカード上の `/app/AiStackChanEx/SC_ExConfig.yaml` の `wakeword.type: 0`（SimpleVox）が前提です。

`wakeword_disable` はfirmwareに実装されていますが、現在のAmigo serverには音声発話からそれを選ぶ判定がありません。「ウェイクワードオフ」で無効化できるとは案内していません。

## 別の仕組みで動く機能

以下は `タッチ` / `いつでも` の会話処理で扱います。

- 天気: server側のキーワード判定。取得には天気の位置設定が必要で、定時取得の時刻はConfigUIで調整します。
- Web検索: 検索キーワードと `AI_SEARCH_PROVIDER` の設定に従います。
- Vision: `見て` / `撮影して`、およびAI判断によるカメラaction。
- 歌: `SONG_TRIGGER` / `SONG_MAP` と、server側に用意した音声ファイルを使います。

設定の詳細は [server連携](server.md)、カメラは [Vision](vision.md) を参照してください。
