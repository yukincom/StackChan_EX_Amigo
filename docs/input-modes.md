# 入力モード（ドラフト）

> 2026-09-11時点の操作・導入ドラフトです。

EX Amigoでは、顔のタッチ領域を長押しして、会話の入力方法を **タッチ** と **いつでも** から選べます。

## タッチ

顔へ一度触れるとマイクが起動し、一回会話します。

## いつでも

顔へ毎回触れたり、ウェイクワードを言ったりしなくても、続けて会話できます。人の声ではないと判定した音は会話に送りません。

録音と返答は順番に行うため、StackChanが話している途中の割込みには対応していません。電話や他の人同士の会話を見分けて返事を控え、名前を呼ばれたら会話へ戻る機能は現在評価中です。

## モードを変更する

1. 顔のタッチ領域を2秒長押しする。
2. `タッチ` と `いつでも` の2ボタンが表示されたら、いったん指を離す。
3. 選びたいボタンに触れる。

どちらのモードからでも同じ操作で切り替えられます。選択は保存されないため、別のアプリへ移った後は選び直してください。

利用前の設定は [基本的な利用方法](basic_usage.md#入力モードcores3) を参照してください。

## 確認済み範囲

CoreS3へのFlash、対応serverとの短い実会話、音声認識から返答再生までの一周は確認済みです。

カメラ・歌・検索を組み合わせた実機確認、長時間運転、部屋や音量が変わったときの誤反応、物理SD上の全音声は別途確認が必要です。技術的な検証記録は [FW-005](../doc/conversation-actions-2026-09-11.md) に残しています。
